# Suggested milestones

## P0 — Framing & safeguards
Close when the core loop, privacy boundary, accessibility baseline and first architecture decisions are explicit.

## P1 — Functional MVP
Close when the capture → start → interrupt → resume loop works locally on a real device.

## P2 — Advanced prototype
Close after optional advanced functions have been tested without increasing core friction.

## P3 — Documented beta
Close when testing, privacy, accessibility and release documentation are ready for a broader beta.

## P4 — Post-validation
Only for candidates that should not consume MVP time.
