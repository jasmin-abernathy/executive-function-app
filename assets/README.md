# Visual assets

Only assets with a known source and licence belong here.

For each non-original asset, keep a nearby note containing:

- author / project;
- source URL;
- licence name and version;
- whether modifications were made;
- required attribution text, if any.

Do not add generated imagery simply to fill the repository. Product screenshots should use synthetic/demo data only.
