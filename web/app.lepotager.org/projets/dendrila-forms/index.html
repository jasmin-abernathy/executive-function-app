Dendrila Forms

Un moteur léger et auto-hébergeable pour créer des enquêtes, questionnaires et interviews à partir de fichiers JSON. Projet libre inspiré des enquêtes TDAH et des interviews advarP.

État actuel
0.1.0-alpha · démonstration technique
Technologie
PHP 8.1+ · JSON · AGPL-3.0-or-later
Informations vérifiées
10 octobre 2026

Ce qui fonctionne dans le prototype

  • Modèles de formulaires JSON : sections, texte libre, choix simples ou multiples et échelles
  • Une question par écran avec progression, retour arrière et conditions d'affichage
  • Code privé pour reprendre un brouillon, relire, verrouiller l'envoi et demander la suppression

Pas encore prêt pour recueillir de vraies réponses

Ne pas utiliser ce prototype pour des données personnelles ou sensibles, des mineurs, des entretiens privés ou des enquêtes en production.

Les invitations privées, la gestion des personnes, les statistiques et l'administration complète restent à réaliser. La purge des réponses nécessite un cron configuré. L'hébergement doit exposer uniquement public/, jamais le code source ou les données.

Code source et contributions

Le projet est libre. Vous pouvez l'essayer localement avec les exemples fictifs, consulter le code et proposer une amélioration.
