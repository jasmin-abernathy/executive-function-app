WordPress

Dendrila Age Assurance

Un socle de vérification d’âge pour WordPress conçu pour limiter les données échangées et protéger les contenus sélectionnés avant leur affichage.

État actuel
Socle en PR · non publié
Plateforme
WordPress · PHP 7.4+ · prototype
Informations revues
11 octobre 2026

Fonctionnalités en développement

  • Protection globale ou de pages choisies avant le rendu du thème.
  • Adaptateur serveur AgeVerif OAuth2, avec justificatif local signé de courte durée.
  • Absence de conservation prévue des documents d’identité, du pays ou des jetons d’accès fournisseur.
  • Contrôles intégrés des pages, API REST, archives, flux et plans de site WordPress.

Limites actuelles

Une image ou un fichier déjà accessible directement par URL ou CDN peut encore contourner la protection PHP ; cette limite doit être résolue pour les médias sensibles. Aucun agrément réglementaire ni conformité garantie. Développement sur PR non fusionnée.

Suivre le développement

Le dépôt de ce projet reste privé pendant les travaux d’intégration et les tests pilotes.
