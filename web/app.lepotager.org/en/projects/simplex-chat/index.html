What is SimpleX?

SimpleX Chat offers end-to-end encrypted messaging without requiring a phone number or a global user account identifier. People connect through invitation links or codes, while a decentralised relay network handles message delivery. This reduces some forms of contact-graph surveillance; it is not an absolute guarantee of anonymity.

SimpleX is developed by its own team. Le Potager du Web is neither the publisher nor the distributor of the official app.

My current contributions

  • Proximity sensor during calls — issue #7507: proposed Android setting to avoid automatic screen blanking during a call. PR #2 on my fork. Android compilation and JVM tests passed on the PR branch (GitHub Actions run). Emulator testing for this branch and physical-device checks with earpiece, loudspeaker and Bluetooth headset are still required.
  • Manual export towards Resilience Vault: an initial proposal for a controlled SimpleX export with security preconditions. PR #1 on my fork. Ten isolated Kotlin tests passed, but complete Android compilation and restore testing on a physical device remain unverified. This is not a verified encrypted remote backup, remote wipe or automatic uninstallation feature.

Neither proposed change should be presented as part of an official SimpleX release. Both still require review and testing.

Potential next step: group calling

I am also reviewing community requests for group audio/video calling (#5138) and group voice rooms (#2398). This is exploratory work only: no working group-call feature has been delivered through these contributions.

Transparency and limitations

  • I contribute to an existing project, rather than claiming to have built a new messenger.
  • PRs on my fork do not imply endorsement or acceptance by the SimpleX team.
  • Real-device testing and security validation remain necessary before relying on these changes for sensitive use.
