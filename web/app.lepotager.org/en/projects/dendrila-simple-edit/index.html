WordPress

Dendrila Simple Edit

A guided editing interface that lets designated people update approved website content without changing the site's layout or technical configuration.

Current stage
Prototype in development branches and PRs · unreleased
Platform
WordPress 6.5+ · PHP 7.4+
Reviewed
11 October 2026

What this project is building

  • A minimum-permission “Site Manager” role.
  • Explicitly approved global text regions, with optional limited ACF support.
  • Choice of approved images without blanket upload permissions.
  • PR work on delegated newsletter drafts and WooCommerce product fields.

Current limitations

Divi, Elementor, ACF and WooCommerce integrations still require real WordPress tests. Feature PRs are not merged and no deployment has been validated.

Development and feedback

This project’s code repository is private while development and real-world testing continue.
