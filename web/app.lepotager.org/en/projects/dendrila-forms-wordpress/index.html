WordPress

Dendrila Forms for WordPress

Bring the independent Dendrila Forms engine into WordPress, with form administration and shortcode embedding.

Current stage
0.1.0-alpha · demo, not for real data collection
Platform
WordPress 6.5+ · PHP 8.1+ · AGPL
Reviewed
11 October 2026

What this project is building

  • Conditional questions, progress and back navigation without requiring JavaScript.
  • Resume drafts with a private code; administrator export of submitted responses.
  • Dedicated WordPress storage, scheduled cleanup and no mandatory third-party trackers.
  • Forms must be explicitly enabled before accepting responses.

Current limitations

Private invitations, attachments, public statistics and a visual editor are not yet available. No validated installation on a real WordPress. Form pages must be excluded from shared caches to avoid exposing recovery codes or response states.
