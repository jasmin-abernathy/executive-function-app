WordPress

Dendrila Form Sentinel

A local watchdog that looks for form references and alerts administrators about missing or disabled forms without collecting visitors' responses.

Current stage
0.1.0-alpha · inventory and alerts only
Platform
WordPress 6.5+ · PHP 8.1+ · GPL
Reviewed
11 October 2026

What this project is building

  • Detects references from Contact Form 7, WPForms, Fluent Forms, Forminator, Gravity Forms and Dendrila Forms.
  • Read-only recognition of native Divi 4/5 and Elementor Pro form modules.
  • Compares successive scans to reduce alerts from transient anomalies.
  • Dashboard and optional e-mail alerts, without an external API.

Current limitations

Finding a form does not prove it renders, submits or delivers messages. Real submission and delivery tests are not implemented. A real WordPress pilot is still needed.

Development and feedback

This project’s code repository is private while development and real-world testing continue.
