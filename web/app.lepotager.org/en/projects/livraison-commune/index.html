Livraison Commune

A local delivery platform designed to be governed by merchants, couriers and residents, rather than a centralised intermediary.

Current stage
Browser demo and local test lab · not launched
Technology
JavaScript · Python 3.12+ · SQLite · AGPL-3.0-only
Reviewed
24 October 2026

Two separate, fully fictional demos

  • Standalone browser demo: editable imaginary stores, product stocks, local basket, pickup and delivery flows within one browser.
  • Local multi-user lab: a separate Python/SQLite server and interface, two fictional territories and server-side permission checks.
  • Transactional orders, voluntary delivery offers, penalty-free refusals, prevention of double assignment and recovery after lost responses. JavaScript, Python and Chromium tests passed.

Not an operational marketplace

No participating businesses or couriers, real orders, payments, authenticated accounts, SMS or GPS tracking. The local test server deliberately allows anyone with local access to select fictional identities and is neither publicly deployed nor suitable for production authentication.

Further work includes production security, testing accessibility on real devices, partner workflows, legal requirements and collectively agreed governance, fees and working conditions.

Help shape the project

Interested merchants, couriers and residents can discuss needs and governance. The development repository is currently private.
