What is Verger Associations for?

Meetings, collective decisions, assigned tasks, welcoming members, running events and requesting help are often scattered across different tools. Verger Associations brings these activities together for associations, community groups and cooperatives.

The association dashboard opens first in the APK. Chat is not a second app that users must install: its encrypted SimpleX engine runs within Verger.

How does an association set itself up?

  1. Introduce the association. Enter its name and description.
  2. Personalise the interface. Add a logo, choose a colour and select the modules you need.
  3. Set up an administrator. Supply an email address and create the administrator account.
  4. Verify the domain. Either add a temporary DNS TXT record or download a verification text file to place in your website’s public root; the server checks your chosen method.
  5. Start using Verger. Open your chosen tools from the dashboard; sensitive settings are kept in a separate administrator area.

DNS TXT or HTTPS file verification shows that the person technically controls the domain or website, not that they have proven their legal mandate to represent the association. No hosting password or domain registrar credentials are required.

The setup wizard and both verification methods (DNS TXT and HTTPS file) are implemented and automatically tested, but public self-service registration is not yet live. Associations without their own domain can explore the prototype locally.

Embedded encrypted messaging, not a social network

The Android prototype reuses SimpleX Chat end-to-end encryption in a single APK. Members access their association’s private group instead of creating arbitrary conversations and additional groups from the Verger interface.

Administrators prepare the group and its invitations. Linking it to a Verger space is currently a local action on each phone, and hiding buttons does not replace SimpleX’s own group permissions. French translations are being completed: some messaging screens may still contain English text.

What is tested, and what is still missing?

Implemented and automatically tested

PWA association tools, exports, identified consultations, first-run setup and server-side DNS TXT or HTTPS file verification.

Integrated in the Android prototype

Verger opens first, with association tools and the SimpleX engine bundled into one APK. The Android build succeeded on 6 November; real-device tests are still needed, while the latest additions, including custom logos, require a new build.

Required before wider availability

Real-device testing, complete French messaging, invitation and revocation handling, enforced permissions on all data, isolated synchronization for each association, and server deployment.

Important distinction: SimpleX messages are end-to-end encrypted, but this does not automatically encrypt association management data. The pilot Automerge sync server still relies on a shared token and must not be used to host unrelated associations yet.

Verger does not yet replace association accounting, formal records management or production handling of sensitive information.
