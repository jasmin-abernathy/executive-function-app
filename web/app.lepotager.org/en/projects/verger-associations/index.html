What is Verger Associations for?

Meetings, collective decisions, assigned tasks, welcoming members, running events and requesting help are often scattered across different tools. Verger Associations brings these activities together for associations, community groups and cooperatives.

On launch, users choose the access journey that fits their role. Once signed in, they reach their association dashboard. The end-to-end encrypted SimpleX messaging engine is built into the APK: no separate chat app needs installing.

Three access paths for association members

The opening screen shows these paths in the order below. Choosing a button does not grant permissions: actual privileges come from the account verified by the server.

Volunteers

Sign in, request access to the association, or accept an invitation. Once approved, use the modules made available to members.

Board / founders

Presidency / co-presidency

Create and verify the association space, or sign in with an existing administrator account. Administrators can review access requests and set up encrypted group chat.

Administrators review access requests and, when approved, generate an invitation code to share manually. Automatic email delivery and email-address ownership verification are not yet available.

How does an association set itself up?

  1. Choose “Presidency / co-presidency”. Create an association space or sign in with an administrator account.
  2. Introduce the association. Enter its name and description.
  3. Personalise the interface. Add a logo, pick one accent colour that is automatically applied throughout the interface, and select the modules you need.
  4. Set up an administrator. Supply an email address and create the administrator account.
  5. Verify the domain. Either add a temporary DNS TXT record or download a verification text file to place in your website’s public root; the server checks your chosen method.
  6. Start using Verger. Open your chosen tools from the dashboard; sensitive settings are kept in a separate administrator area.

DNS TXT or HTTPS file verification shows that the person technically controls the domain or website, not that they have proven their legal mandate to represent the association. No hosting password or domain registrar credentials are required.

Public registration is not available yet: this is a restricted pilot. DNS TXT or HTTPS file verification establishes technical control of a domain, not legal authority to represent an association. Expired verification challenges must be generated again. On Android 10+, the proof file is saved directly to Downloads.

Embedded encrypted messaging, not a social network

In the current Android alpha, an authenticated president can open the private-group creation form directly, without supplying a group invitation code. Other members join via an invitation. A first-time encrypted messaging profile is still required, but SimpleX does not need to be installed separately. End-to-end encryption is powered by SimpleX Chat.

The selected group is linked locally to the association on that phone. The latest APK preserves the signed-in Verger dashboard behind messaging so Android Back can return to it. Automated tests passed, but the actual group-creation and navigation flows still need checking on a phone. Group-level permissions remain under SimpleX, and some native chat screens may still include English text.

What is tested, and what is still missing?

Implemented and automatically tested

PWA association features, exports, identified consultations, access requests, server-side roles, DNS TXT/HTTPS file verification, and adaptive colour palettes are covered by automated tests. The pilot server is running over HTTPS and handles accounts.

Integrated in the Android prototype

The same APK embeds Verger and the SimpleX messaging engine. President-led group creation, navigation back to the signed-in home screen, and association theming are included in the successful 7 November 2026 build. Full device testing remains necessary.

Required before wider availability

Actual association-data synchronization across members and devices, complete permissions for local data, Android testing across devices and versions, end-to-end invitation/revocation testing, remaining translations, and security review before public availability.

Two separate systems: SimpleX messages use end-to-end encryption, but association management data is not automatically encrypted. The pilot server already handles accounts, invitations and consultations, while Automerge document synchronization between phones is not yet enabled. Data stays local to each device and can be lost after uninstalling without a backup.

Verger does not yet replace association accounting, formal records management or production handling of sensitive information.
