Dendrila Forms

A lightweight self-hosted engine for surveys, questionnaires and interviews configured with JSON files. An open-source project inspired by ADHD research and advarP interviews.

Current stage
0.1.0-alpha · technical demo
Technology
PHP 8.1+ · JSON · AGPL-3.0-or-later
Reviewed
10 October 2026

What works in the prototype

  • Form templates with JSON sections, free text, single and multiple choices, and scales
  • One question per screen with progress, back navigation and conditional questions
  • Private recovery code for resuming, review, submission locking and user-requested deletion

Not ready for collecting real responses

Do not use this prototype for personal or sensitive information, children, private interviews or production surveys.

Private invitations, person management, statistics and complete administration still need to be implemented. Retention cleanup only runs if a cron is configured. Deployments must expose public/ only, never the source or data directories.
