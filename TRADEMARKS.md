# Names, logo and identity

The software licence applies to source code; it does not automatically grant permission to present a fork as the original project.

The final product name has not yet been selected. Until it is, **“Executive Function App” / “ADHD App” are working descriptions only**.

When a final name, logo and visual identity are adopted, forks should remain free to modify the software while avoiding confusion about origin, endorsement or official status.

This document is a project policy statement, not legal advice.
