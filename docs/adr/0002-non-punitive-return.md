# ADR 0002 — Non-punitive return

**Status:** Accepted  
**Date:** 2026-08

## Context

Many productivity systems reward uninterrupted consistency. For this product, absence or interruption is an expected state rather than misconduct.

## Decision

The product must make returning easy and must not erase progress or add shame after interruption/absence.

## Consequences

- no broken-streak punishment;
- interruption/resume is a core state transition;
- copy should describe what can be done next rather than what the user failed to do;
- gamification, if added, must be optional and compatible with this rule.
