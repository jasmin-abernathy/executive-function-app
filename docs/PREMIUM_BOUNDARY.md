# Free core and premium boundary

This document prevents monetisation experiments from hollowing out the accessibility/usefulness of the core app.

## Must remain in the free core

- essential timer/focus controls;
- quick capture;
- interruption/resume and non-punitive return;
- essential task organization;
- local-first storage;
- accessibility/readability settings;
- basic local notifications;
- export / backup / restore / delete controls;
- privacy controls required to understand or remove data.

## Possible premium candidates after validation

Only if they create ongoing cost or substantial optional power:

- complex third-party integrations;
- cross-device / PC relay convenience;
- advanced automation packs;
- optional cosmetic environments or companion customisation.

## Never acceptable as a paywall

- basic accessibility;
- deleting/exporting one's own data;
- the ability to resume after interruption;
- basic privacy settings;
- removal of advertising (the app should have no advertising in the first place).
